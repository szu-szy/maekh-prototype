# MAEKH Prototype

Static HTML/CSS/Vanilla JS prototype for maekh.com redesign.

**Live demo**: https://szu-szy.github.io/maekh-prototype/

## Stack
- HTML5 / CSS3 / Vanilla ES modules (zero frameworks)
- Roboto font
- Brand: czerń (#000) / biel (#fff) / akcent #fdbc40 / czerwony limited #ce1900
- Brutalist editorial (square corners, sharp easings)

## Pages
- `index.html` — homepage + mega menu + hero + featured + cats (peek bento) + lookbook + testimonials + UGC + newsletter
- `pdp.html` — product detail (czarny longsleeve oversize)
- `collection.html` — collection with sticky filters + 8 products
- `cart.html` — cart full + summary + cross-sell
- `about.html` — story Berlin/Portugal + timeline
- `contact.html` — form + FAQ (smooth collapse)
- `blog.html` — journal magazine
- `login.html` — auth split layout
- `wishlist.html` — saved items
- `polityka.html` — privacy (RODO 13 sekcji)
- `regulamin.html` — terms (12 sekcji)
- `404.html` — not found
